⏺ MoveTo 코루틴의 WaitUntil 조건이 그 역할입니다.

  IEnumerator MoveTo(Vector3 target)
  {
      agent.SetDestination(target);
      yield return null; // 1프레임 대기 — pathPending이 true로 세팅되는 타이밍
      yield return new WaitUntil(() =>
          !agent.pathPending &&                                          // 경로
   계산 완료
          (agent.remainingDistance <= agent.stoppingDistance + 0.05f || // 
  목적지에 충분히 가까움
           agent.pathStatus == NavMeshPathStatus.PathInvalid));          // 또는
   경로 못 찾음(포기)
  }

  - agent.pathPending — NavMesh가 경로를 아직 계산 중이면 true. false가 될
  때까지 대기
  - agent.remainingDistance — 목적지까지 남은 경로 거리. stoppingDistance + 
  0.05f 이하면 도착으로 판단
  - PathInvalid — NavMesh 위에 목적지가 없거나 경로를 아낼 수 없을 때. 무한
  대기를 막기 위한 탈출 조건

  WaitUntil이 끝나면 MoveTo가 반환되고, 다음 줄(ore.IsMined 체크 또는 납품
  루프)이 실행됩니다.

  한 가지 주의할 점은 광석이 NavMesh 위에 정확히 있지 않으면 PathInvalid로 즉시
  빠져나와 채굴 없이 다음 광석을 탐색하게 됩니다. 광석들이 NavMesh bake 범위
