⏺ 플레이어 메시가 Canvas 쿼드와 3D 깊이 버퍼에서 충돌해서 깜빡이는 문제입니다.
  Sorting Layer로 해결합니다.

  에디터에서 할 것:

  1. Project Settings → Tags and Layers → Sorting Layers
  새 레이어 WorldUI 추가 (Default 아래에)
  2. 업그레이드 존 Canvas 컴포넌트
  Sorting Layer → WorldUI
  Order in Layer → 0
  3. 플레이어 Renderer는 그대로 Default 레이어 유지

  WorldUI가 Default보다 나중에 렌더링되므로, 플레이어가 위를 지나도 Canvas가
  항상 위에 그려져 깜빡임이 사라집니다.

  ---
  만약 그래도 바닥과의 Z-파이팅이 있다면 Canvas Y 위치를 +0.01 정도 올리면
  됩니다.
